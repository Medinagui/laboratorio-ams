# 🧪 Laboratório do site

Um lugar para mexer no código do seu site e **ver o resultado na hora**, sem medo de quebrar nada.

## Como usar

1. Abra o laboratório. Do lado esquerdo está o código do site; do lado direito, o resultado ao vivo.
2. Mude o que quiser: título, textos, emoji, cores. O resultado muda enquanto você digita.
3. Gostou? Clique em **📋 Copiar código**.
4. No GitHub, abra o `index.html` do seu repositório `<seu-usuario>.github.io`, clique no lápis ✏️, apague tudo, cole (**Ctrl+V**) e clique em **Commit changes**.
5. Espere mais ou menos 1 minuto e abra `https://<seu-usuario>.github.io`. 🎉

## Bom saber

- **Seu trabalho fica guardado neste navegador.** Pode fechar e abrir de novo que ele continua lá. Mas só neste computador e neste navegador: antes de ir embora, copie o código e salve no GitHub.
- **Quebrou tudo?** O botão **↩️ Voltar ao modelo** traz o código original de volta (e apaga o que você mudou).
- **🔍 Letra grande** deixa tudo maior, bom para mostrar na TV.
- **Sem internet?** Este laboratório é um arquivo só (`index.html`). Dá para baixar e abrir direto no navegador, com dois cliques.

## 🔒 Regra de privacidade

O seu site é público. Fale de um **interesse** seu (hobby, jogo, time, banda). Use só o primeiro nome ou um apelido, se quiser. **Nada de** foto do rosto (nem de colegas), escola, cidade, telefone, e-mail ou rede social.
